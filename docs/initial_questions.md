# Initial Questions Supported by the Three Real Datasets

These questions are objective and can be verified directly from the fixed snapshot.

1. How many active public schools are located in each neighborhood?
2. Which neighborhoods contain the most open park features?
3. Which active elementary schools are within one mile of an open park feature?
4. What is the nearest open park feature to each active school?
5. Which open park features intersect a selected neighborhood?
6. Which neighborhoods contain at least three active schools and two open park features?
7. Which active schools have no open park feature within one mile?
8. What is the average distance from active schools to their nearest open park feature by neighborhood?
9. Which open park features have the largest number of active schools within one mile?
10. Which neighborhoods contain both active elementary and active high-school records?

Before presenting these questions to end users, define whether trail, school-playground, library, county, and open-space records should be included in the phrase “park.”
