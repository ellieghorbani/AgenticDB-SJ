# Changelog

## 1.0.0 — AgenticDB-SJ portfolio release

### Added

- Reproducible ingestion of real school, park, and neighborhood datasets
- PostgreSQL and PostGIS schemas, views, indexes, and provenance tracking
- Ten manually reviewed relational and spatial gold queries
- Read-only FastAPI database service
- Allowlisted schema retrieval and typed query planning
- Deterministic parameterized SQL generation
- SQLGlot AST validation and adversarial safety tests
- Restricted-role, timeout-bounded, read-only execution
- Traced six-tool agent orchestration and evidence-backed answers
- pgvector semantic and metadata-filtered hybrid retrieval
- Local MiniLM and hosted OpenAI embedding providers
- OpenAI Structured Outputs planning with deterministic fallback
- Interactive portfolio demo
- Aggregated release evaluation, final report, CV bullets, and checksums
